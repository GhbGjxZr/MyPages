主题

新手入门

从这里开始

Hermes 是什么？简单说，它是一个住在你电脑里的 AI 助手——你用大白话告诉它想做什么， 它就能帮你读代码、改文件、跑命令、查资料。你不需要记住命令，直接说人话就行。

三步开机
1
装好并登录（只需做一次）
在终端运行下面两条命令之一。hermes model 会打开一个向导， 让你选模型服务商并填入密钥（API Key）。如果用本地模型，可以跳过密钥。 
# 打开配置向导：选服务商 + 填密钥
hermes model

# 或者用 Nous Portal（300+ 模型统一订阅，一次登录全搞定）
hermes setup --portal
2
开始第一次对话
进入你的项目文件夹，启动聊天，然后用大白话说出需求。不用背命令，就像跟同事说话。 
cd 我的项目文件夹
hermes chat

# 然后直接说人话，例如：
"帮我看看这个项目是做什么的"
"把登录按钮的颜色改成蓝色"
3
学会 3 个最常用的命令
日常 90% 的场景只需要这三个：/new 开新活、 /title 给当前对话起名字、/resume 回到之前的活。 
/new              # 开一个新对话
/title 修复登录bug  # 给这个对话起个名字
/resume           # 看看以前存过哪些对话
最重要的一句话：你随时可以直接打字纠正它，比如中途说"等等，改成 JSON 格式"， 不用重头再来。这是 Hermes 最舒服的用法。
开始之前，你需要准备什么
方式 A：用云端模型
需要一个模型服务商的 API Key（如 Anthropic / OpenAI / Google）。花钱买算力，效果最好，联网可用。
方式 B：用本地模型
需要一张显卡（显存越大越好）。完全离线、不要钱、数据不出本机，但速度取决于你的硬件。
方式 C：统一订阅
用 hermes setup --portal 一次登录，300+ 模型随便切换，不用逐个配密钥。
先搞懂这几个词，后面就不懵了
会话（Session）
就是你和 AI 的一次完整聊天。不同任务建议开不同会话，互不干扰。
斜杠命令
以 / 开头的指令，比如 /new。在输入框打 / 就会弹出全部命令。
上下文（Context）
AI 一次能"记住"的对话内容量。聊太长会记不住开头，这时用 /compress 压缩一下。
Token
计费单位，粗略理解成"字数"。输入的文字和 AI 的回答都算 token，这就是为什么要压缩上下文省钱。
模型（Model）
AI 的"大脑"。不同模型能力、价格、速度不同，可随时切换。
审批模式
AI 执行危险操作（如删文件）前要不要先问你。新手建议开"智能审批"，安全第一。

基础操作 · 常用命令

日常交互

下面每条命令都按「是什么 → 什么时候用 → 怎么用 → 注意什么」讲清楚。命令可以直接点右上角复制。

管理对话
/new开新对话
作用开启一个全新的对话，和之前的聊天彻底分开。
何时用要开始一个不相关的新任务时，避免旧对话干扰它。
/new              # 直接开新对话
/new 周报生成器     # 开新对话并直接命名
/title给对话起名
作用给当前对话起个好记的名字，替代随机编号。
何时用打算以后还要回来继续这个任务时，先起名再干活。
/title 修复登录bug
/resume回到旧对话
作用列出所有已命名的对话，或直接跳回某一个。
何时用关掉程序后想接着上次干，或在多个任务间来回切。
/resume               # 看看存了哪些对话
/resume 修复登录bug    # 直接回到那个对话
只有用 /title 起过名的对话才能被 /resume 找回。没起名的话关掉就找不回来了。
/sethome设为主通道
作用把当前聊天设成"主通道"，用于接收网关（如手机推送）消息。
何时用只在第一次配置消息网关时需要，日常用不到。
/sethome
控制上下文（省钱 + 防失忆）
/compress压缩记忆
作用把冗长的聊天记录压缩成简短摘要，腾出空间。
何时用聊了很久、感觉 AI 开始忘记前面说过的话，或提示上下文快满时。
/compress
/context查看占用
作用显示当前上下文用了多少、还剩多少。
何时用想知道要不要压缩时，先看一眼这个。
/context
/stop紧急停止
作用立刻停掉 AI 正在做的事或后台进程。
何时用发现它跑偏了、卡住了、或在乱改文件时，先喊停。
/stop
模型与安全
/model切换模型
作用在已配置好的模型之间热切换，当前对话立刻生效。
何时用这个任务太难想换个更强的模型，或太简单想换个便宜的。
/model                        # 看看有哪些模型可切
/model anthropic/claude-sonnet-4.6
/model openai/gpt-5.4
只能切已经配置过的模型。要加新服务商，得退出对话运行 hermes model。
/approve批准危险操作
作用批准 AI 执行被判定为高风险的命今。
何时用它弹出"这条命令需要批准"时，你确认没问题再批。
/approve session   # 本次对话内都放行
/approve always    # 以后都放行（谨慎使用）
新手别用 always。建议用"智能审批"模式，让便宜小模型帮你判断低风险命令。
/diff查看改动
作用显示这个对话里 AI 到底改了哪些代码。
何时用在提交代码前，检查它有没有乱改东西。
/diff
干活与效率
/init认识项目
作用扫描整个项目，自动生成一份 AGENTS.md 说明文件。
何时用刚接手一个新项目时先跑它，AI 后面就更懂这个项目。
/init
/skills查看技能
作用列出 AI 当前会用的"技能"（扩展能力）。
何时用想知道它能干哪些 specialised 的活，或搜某个技能。
/skills              # 列出全部
/skills search docker # 搜跟 docker 有关的
!命令直接跑 shell
作用前面加 ! 直接执行系统命今，不消耗 AI 轮次。
何时用只是想自己跑个命令（如 ls、git status），不想浪费 AI。
!ls
!git status
快捷键
快捷键作用
Ctrl + K / ⌘K打开命令总控台，可搜索所有设置和命令
Ctrl + Shift + S显示/隐藏底部状态栏（看模型、审批模式）
Esc Esc（双击）丢弃正在输入的草稿
Ctrl + S暂存写了一半的 prompt
执行中想改主意？直接打字说"等等，把日志改成 JSON 格式"就行， Hermes 会保留已完成的部分并按新要求调整，不用 /stop 重来。

核心配置 · 模型与省钱

进阶一点

这一页讲怎么换"大脑"（模型）、怎么少花钱、怎么完全离线跑。新手先用默认配置就行，等熟悉了再来看。

三种模型切换方式（别搞混）
最容易踩的坑：仪表板里换模型只对新建的对话生效，已经打开的聊天不变。 想让当前对话立刻换模型，必须用 /model 命令。
# ① 加新服务商 / 填密钥（要退出对话）
hermes model

# ② 当前对话里热切换（只切已配置的）
/model anthropic/claude-sonnet-4.6
/model openai/gpt-5.4
/model google/gemini-2.5-pro

# ③ 统一订阅，一次登录 300+ 模型
hermes setup --portal
辅助模型：省钱的关键

Hermes 会把一些不重要的杂活（起标题、看图、压缩记录）交给便宜的小模型， 让贵的主模型专心干核心推理。这一项配置好，成本能降很多。

Title Gen（起标题）
用便宜模型给对话起名字，效果和贵模型差不多，成本约 $0.10/M。
Vision（看图）
主模型不支持看图时（如 DeepSeek），指向 gpt-4o-mini 之类便宜的视觉模型。
Compression（压缩）
用快模型做摘要，成本能降到主模型的 1/50。
Approval（审批）
智能审批模式下，让小模型判断低风险命令，不用每次都麻烦主模型。
# 命令行设置某个槽位
hermes config set auxiliary.title_gen.model google/gemini-3-flash-preview

# 或在仪表板里：Models → 展开 Show auxiliary
本地模型：完全离线、不花钱

想不联网、不花钱、数据完全不出本机？用本地模型。Hermes 支持 Unsloth、Ollama、LM Studio 等。 

# 方式一：内置本地运行时（最省事）
# 设置 → Providers → Local Models
# Install runtime → 选模型 → Download → Use

# 方式二：用 Unsloth 起服务
unsloth start hermes --model unsloth/Qwen3.6-27B-GGUF --temp 1.0 --top-p 0.95

# 方式三：Ollama 一键启动
ollama launch hermes-desktop

# 方式四：连接已有的本地服务（VLLM / SGLang / llama-server）
# hermes model 里选 "Custom endpoint"，填 http://127.0.0.1:8080
硬要求：本地模型上下文至少要 64K tokens，否则 Hermes 会拒绝启动。 llama.cpp 加 --ctx-size 65536，Ollama 加 -c 65536。
自定义端点 / 命名服务商
# 配好自定义端点后，对话里这样切
/model custom:qwen-2.5
/model custom         # 端点只加载了一个模型时，自动选它
/model local:qwen-2.5 # 三段式：给服务商起个名字
想确认现在用的是哪个模型？看欢迎横幅，或直接输入 /model（不带参数）。

场景实战 · 我想…

照着做就行

按你的目的找对应做法，每一步都能直接照抄。

我想少花点钱
把杂活交给便宜模型，主模型只干核心活。
做法：仪表板 → Models → Show auxiliary，把四个槽位都填上便宜模型（flash / mini / haiku 级别）。 
hermes config set auxiliary.title_gen.model google/gemini-3-flash-preview
/compress   # 聊太久时记得压缩，直接省 token
我想完全离线用
不联网、不花钱、数据不出本机。
做法：设置 → Providers → Local Models → Install runtime → 选模型 → Download → Use。 或用 Ollama：ollama launch hermes-desktop。
记得把上下文设到 65536 以上，否则启动会被拒绝。空闲 15 分钟后模型会自动卸载释放显存。
我想同时干好几件事
用多个命名会话并行处理不同任务，互不干扰。
做法：每个任务开一个会话并立刻起名，之后用 /resume 来回跳。 
/new 重构用户模块
/title 重构用户模块
# ……切到别的活……
/resume 重构用户模块   # 回来接着干
重构用户模块
左侧会话列表 + 右侧对话区（示意图）
我想让它帮我写代码
先让它认识项目，再提需求，最后检查改动。
流程：/init 生成项目说明 → 用大白话提需求 → /diff 检查它改了什么。 
/init
# "给登录接口加上参数校验"
/diff
我怕它乱删我文件
用审批模式管住危险操作。
做法：设置 → 安全 → 审批模式，选智能审批。危险命令会先问你， 确认后用 /approve session 放行；跑偏了就 /stop。
新手不要用 /approve always，那等于永久放行所有危险命令。
它开始忘事了 / 变慢了
上下文塞太满，先看看占用再压缩。
做法：先 /context 看占用，接近上限就 /compress 压缩。 如果还不理想，/new 开个干净的新对话。

新手最常踩的 6 个坑
在仪表板换了模型，当前对话怎么没变？
仪表板（或 hermes model）切换只对新建的对话生效，已打开的聊天标签页不受影响。想让当前对话立刻生效，用 /model 模型名 命令。
关掉程序后，之前的对话找不回来了？
只有用 /title 起过名的对话才会被保存，之后用 /resume 能找回。没起名的对话关掉就没了，所以重要任务请先 /title。
本地模型启动失败 / 被拒绝？
Hermes 要求最小 64K tokens 上下文。llama.cpp 加 --ctx-size 65536，Ollama 加 -c 65536，否则启动时会直接拒绝。
聊着聊着 AI 开始忘记前面的内容？
上下文快满了。先 /context 看占用，再 /compress 压缩成摘要。压缩既能"续命"又能省钱。实在不行就 /new 开新的。
它要执行一条我看不懂的危险命令，怎么办？
先 /stop 喊停，看清命令内容再决定。别用 /approve always，那是永久放行。建议设置 → 安全 → 审批模式选智能审批，让小模型先帮你筛一遍低风险命令。
/model 切不到我想用的新模型？
/model 只能切已经配置过的模型。要添加新的服务商（填 API Key、OAuth 登录），得退出对话后在终端运行 hermes model 走配置向导。
记不住命令？在输入框直接打 / 就会弹出全部命令列表； 或者按 Ctrl+K（Mac ⌘K）打开命令总控台搜索。真不用背。
